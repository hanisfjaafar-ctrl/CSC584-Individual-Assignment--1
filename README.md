1. Project Description
   The Personal Profile Web Application is a a web-based application developed to allow users to create and submit their personal profiles through an online form.

   Users need to enter their personal information, including name, student ID, programme, email, hobbies, and a short self-introduction. After submitting the form, the application displays the submitted information on a profile page.

2. Technologies Used
   The following technologies were used to develop this project:
     1. HTML – Structures the web pages and profile form.
     2. CSS– Styles the website, including colours, layouts, buttons, and responsive design.
     3. Java – Servlet acts as the middleman between the HTML form, Java processing and the response displayed to the user.
     4. JSP (JavaServer Pages) – Processes and displays submitted profile information.

3. Software Requirements
   The following software is required to run this application:
     1. NetBeans IDE 8.2
     2. Java Development Kit (JDK)
     3. GlassFish Server 4.1.1
     4. Google Chrome or another modern web browser

4. How to Run the Application
     1. Download or clone this repository to your computer.
     2. Open NetBeans IDE 8.2.
     3. Select File → Open Project
     4. Browse to the downloaded project folder.
     5. Select the PersonalProfile project.
     6. Right-click the project and select Run.
     7. Wait for the application to deploy successfully.
       8. The application will open in your default web browser.
